## 📌 Sobre o Projeto

O objetivo deste projeto é construir uma ferramenta prática e funcional no Microsoft Excel para auxiliar no acompanhamento e controle financeiro de carteiras de investimentos (Ações, FIIs, Renda Fixa, Criptomoedas, etc.). 

A planilha visa automatizar o cálculo de rendimentos, alocação de ativos e consolidação de patrimônio, oferecendo suporte visual para a tomada de decisões financeiras.

---

## 🎯 Objetivos e Aprendizados

Durante o desenvolvimento deste desafio, foram colocados em prática os seguintes conceitos e recursos do Excel:

- **Estruturação de Dados:** Organização de tabelas dinâmicas e padronização de entradas (entradas, saídas, dividendos e aportes).
- **Fórmulas e Funções Principais:**
  - `PROCV` / `PROCX` para busca de dados e cotações.
  - `SE`, `E`, `OU` para validações e condicionais.
  - `SOMASE` / `SOMASES` para consolidação do patrimônio por categoria/ativo.
  - `HOJE()` e funções de data para cálculo de tempo de rendimento.
- **Formatação Condicional:** Destaque visual automático para rentabilidade (positiva/negativa), metas atingidas e alertas de rebalanceamento.
- **Tabelas Dinâmicas e Dashboards:** Agrupamento de dados e geração de gráficos interativos para visualização da alocação de ativos e evolução patrimonial.

---

## 📊 Funcionalidades da Planilha

- **[x] Lançamento de Operações:** Aba dedicada para registrar compras, vendas e proventos recebidos.
- **[x] Consolidação de Carteira:** Resumo automático da posição atual, preço médio de compra, valor investido e valor de mercado.
- **[x] Análise de Rentabilidade:** Cálculo de ganho/perda em R$ e variação percentual (%).
- **[x] Distribuição de Ativos:** Visualização gráfica do percentual investido por classe de ativo (Renda Fixa, Ações, FIIs, etc.).
- **[x] Dashboard Interativo:** Resumo executivo com indicadores-chave (KPIs) e gráficos de desempenho.

## 🚀 Como Utilizar

1. **Faça o Download ou Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/Desafio-DIO-Excel---Controle-de-Investimentos.git
   ```
2. **Abra o arquivo:**
   - Navegue até a pasta `src/` e abra o arquivo `Controle_de_Investimentos.xlsx` no Microsoft Excel (recomendado Excel 2016 ou superior / Microsoft 365).
3. **Insira seus dados:**
   - Vá para a aba de **Lançamentos** e cadastre suas transações (Tipo de ativo, quantidade, preço unitário e taxas).
4. **Visualize os resultados:**
   - Acesse a aba **Dashboard** para acompanhar a evolução do seu patrimônio e rentabilidade de forma visual.
