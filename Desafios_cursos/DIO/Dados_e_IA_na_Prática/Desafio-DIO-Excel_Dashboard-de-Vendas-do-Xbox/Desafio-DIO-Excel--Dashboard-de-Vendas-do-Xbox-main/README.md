# 🎮 Desafio DIO: Dashboard de Vendas do Xbox com Excel

> Repositório desenvolvido para o desafio prático de construção de um **Dashboard de Vendas do Xbox** no Microsoft Excel, proposto pela [Digital Innovation One (DIO)](https://www.dio.me/?utm_source=gemini).

## 📌 Sobre o Projeto

Este projeto consiste na análise de dados e construção de um **painel interativo (Dashboard)** no Microsoft Excel focado no ecossistema de vendas da marca **Xbox** (consoles, jogos, acessórios e assinaturas como Xbox Game Pass). 

O objetivo principal é transformar dados brutos de vendas em indicadores visuais e dinâmicos para apoiar a tomada de decisões estratégicas de negócios e marketing.

---

## 🎯 Objetivos e Competências Desenvolvidas

* **Tratamento e Modelagem de Dados:** Limpeza, padronização e estruturação dos dados brutos de vendas.
* **Tabelas Dinâmicas:** Agrupamento rápido de dados por região, categoria de produto, período e canal de venda.
* **Segmentadores de Dados (Slicers) e Linhas do Tempo:** Filtros interativos por período, produto e região.
* **Fórmulas e Funções Principais:**
  * `SOMASE` / `SOMASES` para métricas consolidadas.
  * `PROCX` / `PROCV` para relacionamento de tabelas de produtos e clientes.
  * `MÁXIMO`, `MÍNIMO` e `MÉDIA` para análise de ticket médio e destaques de venda.
* **Design de Dashboards no Excel:** Layout intuitivo, paleta de cores temática (inspirada no universo Xbox) e hierarquia visual clara.

---

## 📊 Indicadores e Visualizações (KPIs)

O painel reúne os principais **KPIs (Key Performance Indicators)** de vendas:

* **[x] Faturamento Total:** Valor acumulado das vendas no período analisado.
* **[x] Unidades Vendidas:** Quantidade total de itens comercializados (Consoles, Jogos, Acessórios).
* **[x] Ticket Médio:** Valor médio gasto por transação.
* **[x] Vendas por Categoria:** Distribuição das receitas entre Consoles (Series X|S), Jogos, Acessórios e Assinaturas (Game Pass).
* **[x] Desempenho Regional:** Comparativo de vendas por país/região ou canal de distribuição (Loja Física vs. E-commerce).
* **[x] Evolução Temporal:** Gráficos de linha acompanhando o crescimento de vendas mês a mês / trimestre a trimestre.

## 🚀 Como Utilizar

1. **Faça o Download ou Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/Desafio-DIO-Excel---Dashboard-Vendas-Xbox.git
   ```

2. **Abra o arquivo:**
   * Navegue até a pasta `src/` e abra o arquivo `Dashboard_Vendas_Xbox.xlsx` no Microsoft Excel (recomendado Excel 2016 ou superior / Microsoft 365).

3. **Interaja com o Dashboard:**
   * Utilize as **Slicers (Segmentadores de Dados)** situadas nas laterais/topo do painel para filtrar os gráficos por ano, categoria ou país em tempo real.
