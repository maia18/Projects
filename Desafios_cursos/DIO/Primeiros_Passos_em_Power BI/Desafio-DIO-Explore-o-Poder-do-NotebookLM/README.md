# Desafio DIO - Treinando uma IA de Aprendizagem: Explore o Poder do NotebookLM 🧠🤖

> **Bootcamp / Curso:** Digital Innovation One (DIO)
> **Tema:** Inteligência Artificial, Curadoria de Dados e Assistentes de Aprendizagem

---

## 📌 Visão Geral

Este repositório documenta a minha experiência prática com o **Google NotebookLM**, explorando suas capacidades como um assistente de IA focado em aprendizagem e análise aprofundada de documentos (*Source-Grounded AI*). 

O objetivo do projeto foi criar um "cérebro digital" personalizado, alimentá-lo com referências específicas e utilizar a IA generativa para extrair insights, criar materiais de estudo e organizar grandes volumes de informação de forma interativa.

---

## 🎯 Objetivos do Desafio

- **Curadoria e Ingestão:** Selecionar e carregar materiais relevantes (PDFs, URLs, notas em texto) para construir a base de conhecimento.
- **Interação Focada:** Realizar consultas e testes de *prompt engineering*, garantindo que a IA responda com base exclusivamente nas fontes fornecidas, evitando alucinações.
- **Geração de Artefatos:** Explorar as ferramentas nativas para criar FAQs, guias de estudo, cronogramas e resumos em áudio (Audio Overview / Podcast).
- **Apoio Educacional:** Validar o uso da ferramenta para acelerar a criação de materiais de apoio para estudos e monitorias acadêmicas.

## 🚀 Como reproduzir este projeto

1. Acesse o [Google NotebookLM](https://notebooklm.google.com/).
2. Crie um novo "Notebook".
3. Faça o upload das suas referências (PDFs, links, textos).
4. Utilize a barra de chat para fazer perguntas direcionadas ao material.
5. Acesse o painel de "Guia do Notebook" para gerar os materiais de estudo automáticos.
